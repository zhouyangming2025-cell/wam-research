## 1. Executive result

Wave 3 establishes that `world model + action/planning` currently spans at least six distinct interfaces:

```text
1. shared historical representation
2. shared autoregressive world-action language
3. online world-generator hidden state as planner input
4. future ego-intent representation as action-retrieval key
5. candidate-specific future latent as action evaluator
6. learned world as imagined RL training environment
```

These are architecturally and causally different. A paper should not be interpreted merely by asking whether it “has a world model.” The scientifically relevant question is:

```text
WHERE does predictive/world information enter the decision process?
```

## 2. Unified inference/training interface map

| paper | what is predicted / represented | action relation | planner use | world model used online for current action? | main role |
|---|---|---|---|---|---|
| **Epona** | compact historical latent `F`; visual future generated by VisDiT | trajectory and visual heads share `F`; visual rollout can be action-conditioned | TrajDiT directly generates trajectory from shared latent | visual generator not required for planning | joint multi-task representation / modular world-action generation |
| **DrivingGPT** | interleaved image + framewise action tokens | action and world tokens share vocabulary/causal sequence | action tokens generated by same autoregressive Transformer | shared sequence is online at formulation level; optimized decode path not source-audited | unified world-action language |
| **DriveLaW** | Video-DiT denoising hidden state | hidden world state conditions Action DiT | Action DiT consumes world-generator latent directly | **yes** | generative world hidden state as planner state |
| **Auto-JEPA** | future ego-trajectory latent / continuous intent | scene predicts one future action-intent representation | intent retrieves trajectories; scorer/gate selects | **yes, intent latent** | decision-oriented predictive compression |
| **DA-WAM** | one future latent per trajectory candidate | each candidate conditions its own predicted future | candidate scorer consumes `(current, action, future_i)` | **yes** | candidate consequence evaluation |
| **Think2Drive** | recurrent latent transition + reward + termination | actor action drives imagined world transition | actor/critic trained in latent imagination | multi-step imagination mainly training-time; latent state remains actor input | model-based RL / neural training simulator |

## 3. The key distinction is not “explicit future vs latent future”

A more useful hierarchy is:

```text
A. world prediction only shapes training
B. world representation remains online but is not rolled out per candidate
C. future representation directly enters current action selection
D. candidate action generates a candidate-specific future used for ranking
E. world model creates imagined trajectories/rewards to train a policy
```

Examples:

```text
Epona     ≈ A/B
DriveLaW  ≈ B/C
Auto-JEPA ≈ C
DA-WAM    ≈ D
Think2Drive ≈ E
```

DrivingGPT cuts across the hierarchy because world/action are modeled as one causal sequence rather than separate branches.

This taxonomy is more useful for planning than `RGB / occupancy / latent` alone.

## 4. Strongest paper-level evidence, with attribution boundaries

### Epona

Best-supported claim:

```text
joint visual-future + trajectory learning improves the shared representation relative to trajectory-only training
```

Boundary:

```text
future visual output is not required in the deployed trajectory path
```

Therefore Epona supports joint predictive representation learning more strongly than online imagined-future evaluation.

### DrivingGPT

Best-supported claim:

```text
one autoregressive model can represent images and actions as a common driving language and generate useful actions
```

Boundary:

```text
no same-model action-only vs world+action matched control has been established in the reviewed evidence
```

Thus successful unification is established; the causal planning contribution of visual-token prediction is less isolated.

### DriveLaW

Strongest evidence:

```text
video-pretraining scale:
85.9 → 87.0 → 87.8 → 89.1 PDMS

representation under planner:
BEV 84.1
VLM hidden 86.5
video latent 89.1

Video-DiT denoising state:
t=1 89.1
t=5 86.9
t=10 23.2
```

Stable interpretation:

```text
planning utility depends strongly on the exact internal predictive/generative representation
```

Boundary: data scale, model capacity and representation semantics are not perfectly disentangled.

### Auto-JEPA

Strongest internal decomposition:

```text
fixed codebook medoid intent              52.6 PDMS
intent retrieval + gate, no scorer        87.6
intent + scorer, no gate                  91.0
full                                      91.3

K=1 / 200 / 300:
87.6 / 91.1 / 91.3
```

Semantic occlusion further shows dynamic-agent masks change the predicted intent `2.97×` more than matched random masks on average.

Stable interpretation:

```text
future ego-motion representation can act as a strongly planning-sensitive predictive target without dense world reconstruction
```

Boundary: strong performance also depends on trajectory-memory coverage and candidate ranking; planning sensitivity is not proof of universal decision sufficiency.

### DA-WAM

Matched future-interface ablation:

```text
No Future Prediction         93.31
Shared Global Future         92.81
Current-Latent Conditioning  93.25
Action-Conditioned Future    93.46
+ Hard Negatives             93.68
```

Stable interpretation:

```text
candidate-specific future alignment provides a small positive increment over a very strong no-future planner;
shared future can be worse than no future;
hard-negative/ranking supervision contributes independently.
```

Critical supervision boundary:

```text
N candidate future outputs are predicted
but only the expert-matched candidate receives direct observed-future latent supervision
```

Thus candidate-specific future output is stronger than candidate-specific future ground truth.

### Think2Drive

Official CARLA-v2 result:

```text
PPO expert:       DS 0.7 / WDS 0.6 / RC 1.0%
Think2Drive:      DS 56.8 / WDS 91.7 / RC 98.6%
```

Stable interpretation:

```text
latent world dynamics + imagined actor/critic training can produce a strong closed-loop policy in a difficult simulator
```

Boundary: success also depends on scenario generation, replay, reward shaping, curriculum, reset and training engineering; the paper does not isolate a pure world-model-only delta.

## 5. Stable cross-paper conclusions after Wave 3

### C1 — future information has no universal positive sign

Across Waves 2–3:

```text
OccWorld: better reconstruction can forecast/plan worse
LAW: longer horizon can plan worse
DriveLaW: different internal denoising state can collapse planning
DA-WAM: shared future can be worse than no future
```

Therefore the meaningful variable is not `amount of future information`, but:

```text
representation × horizon × conditioning × planner interface × supervision
```

### C2 — planning-oriented compression is now a first-class world-model design choice

Auto-JEPA makes the strongest explicit move from:

```text
predict the future world
```

toward:

```text
predict the future implication for ego action
```

This does not prove dense world modeling is unnecessary in all regimes, but it confirms that **decision relevance and world completeness are separate objectives**.

### C3 — online model-based planning is only one member of the field

A WM can help planning through:

```text
training-time auxiliary prediction
pretraining
online hidden state
retrieval intent
candidate consequence scoring
imagined RL policy optimization
```

Therefore the phrase `world-model-assisted planning` must always identify the exact causal interface.

### C4 — stronger architectural world/action coupling is not automatically stronger evidence

DrivingGPT is architecturally highly unified, but its world-model contribution to planning is less causally isolated than some looser systems with strong matched ablations.

Conversely, DA-WAM has an explicit action→future→score chain but only a small matched PDMS gain over its no-future planner.

Thus:

```text
architectural coupling strength
!= planning effect size
!= evidence quality
```

### C5 — the supervision bottleneck changes with interface

Different interfaces encounter different supervision constraints:

```text
Epona / LAW / ViDAR:
observed future can supervise one factual predictive target

Auto-JEPA:
future ego trajectory directly defines the target

DA-WAM:
all candidates need futures, but offline logs directly reveal only one executed future

Think2Drive:
interactive simulator can generate transition/reward experience, then learned WM supplies additional imagined rollouts
```

This is a major structural axis for the field and should remain central in later synthesis.

### C6 — evaluation strength and representation sophistication remain orthogonal

NAVSIM-heavy recent planners may have sophisticated WAM architectures but are evaluated non-reactively.

Think2Drive uses an older Dreamer-style latent WM yet has genuine repeated CARLA closed-loop policy evaluation.

Therefore architectural recency cannot substitute for stronger behavioral evidence.

## 6. Wave-3 comparison against strong non-WM controls

Wave 1 established that high planning scores can arise from:

```text
better action distribution modeling     — DiffusionDrive
better candidate scoring / hard negatives — DriveSuprim
explicit safety/collision optimization  — UniAD and related planners
```

Wave 3 does not remove these competing explanations.

In fact:

```text
Auto-JEPA needs retrieval + scorer/gate
DA-WAM starts from a 93.31 no-future planner
DriveLaW uses a strong Action DiT
Think2Drive uses a full actor-critic + shaped reward stack
```

Hence future work must continue decomposing:

```text
world representation gain
vs action-model gain
vs scorer/value gain
vs supervision gain
vs optimization/training gain
```

## 7. Wave-3 closeout verdict

The Wave-3 stop condition is satisfied.

We can now place all six anchors on one planning-interface map without saying merely “they use a world model.”

```text
Epona      = shared predictive representation / modular heads
DrivingGPT = shared world-action causal sequence
DriveLaW   = online world hidden state → action generator
Auto-JEPA  = predicted future ego intent → retrieval / selection
DA-WAM     = action candidate → future latent → score
Think2Drive= learned world → latent imagination → actor/critic policy learning
```

Wave 3 is therefore **CLOSED**.
