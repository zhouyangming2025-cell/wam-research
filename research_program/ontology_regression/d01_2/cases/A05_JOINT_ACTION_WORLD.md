# Pressure Case A05 — Joint World–Action Sequence

## Boundary question

Does a shared autoregressive world/action process constitute an online `C5/X4/D4` joint carrier, or is it only a shared backbone that should remain a direct policy with a training modifier?

## Closed-set projections

```text
if joint output is runtime:
C5@R + X4 + D4 + P∅ + V=N/A + RJ+W5+E0

if world/action branch is not runtime:
C@T + D∅ + P∅ + R0+W0+E0, with LQ/branch-drop
```

## Result

The ontology provides both legal outcomes without adding a category. The unresolved issue is evidence about the scoped deployment mode, not an abstraction failure.

