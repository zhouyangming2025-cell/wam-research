# 03 — 路线候选与反例检验卡

**状态：PROVISIONAL — 由工作簿生成，不是 taxonomy。**  
本文件保留 core-route 综合中真正有解释力的因果分叉，但拒绝把单例、模式差异或来源不足的条目冒充为稳定路线。

## 候选 R-A：训练期世界相关监督 → 部署期直接策略

**暂定成员：** LAW、Metis；Drive-JEPA PF 仅在 artifact 证据锁定后加入。  
**共享命题：**未来/世界对象在训练中塑造表征或策略，但主部署动作链不要求运行同一未来预测模块。  
**必须成立的证据：**训练图存在 world/future 目标；推理图的真实输入和保留模块可核验；删除预测支路不破坏所述主动作图。  
**主要反例压力：**如果部署仍使用预测状态、候选评分或查询式 world model，则不属于此路线。  
**当前边界：** Epona 不自动加入，因为 planning-only 与视频参与模式必须先拆开；DynFlowDrive 不自动加入，因为其 score/teacher 的部署关系仍不足。

## 候选 R-B：部署期保留世界相关状态 → 单路径动作条件

**暂定成员：** DriveLaW；GraphWorld 为待确认成员。  
**共享命题：**部署保留的不是候选后果评分器，而是进入单一路径动作生成的世界相关状态。  
**必须成立的证据：**该状态在 test-time 真实保留；它经明确接口进入 action/planner；系统不依赖候选集合的比较选择。  
**主要反例压力：**DriveLaW 的 hidden state 不等于显式视觉 rollout；GraphWorld 若最终并非直接条件化动作或实际包含候选解析，应转出。  
**当前边界：**“在线”不是定义；对象、接口和是否拥有选择权才是定义。

## 候选 R-C：候选后果 → 评估 / 奖励 → 选择

**暂定成员：** WoTE、WorldDrive；World4Drive 为待确认成员。  
**共享命题：**规划先形成可比较的候选承诺，再把候选相关未来后果送入评分/奖励/解析器，选择改变最终动作。  
**必须成立的证据：**候选在评估前已明确；未来对象与候选对应；同一 resolver 对候选作比较；选中结果确实决定动作。  
**主要反例压力：**WorldDrive 的部署端可能是蒸馏评分器而不是在线显式未来生成；WoTE 的非反应式环境边界不能被虚构为闭环因果；World4Drive 的真实 inference target 尚待锁定。  
**当前边界：**三者可共享决策拓扑，但不能据此说其未来表征、训练目标或环境交互等同。

|DynFlowDrive|可能揭示训练准则/部署评分的不同生命周期|来源和部署桥不够清晰|补 score、teacher、test-time 图。|
|Discrete-WAM|语义决策到 action token 的结构值得保留|未来 visual/world token 是否进入主部署链未清；暂为单例|拆 joint training 与实际 inference decode。|

## 绝不使用的伪分叉

- “是否有 world model”；
- “是否预测未来”；
- “是否联合训练”；
- “是否能生成视频”；
- “是否迭代”。

这些词只可作为检索提示。它们本身不说明未来对象是否跨过动作桥、是否参与候选选择、或是否在部署保留。

## 提升 / 否决记录

每次核验只允许产生三种结果：

1. **提升**：补足证据后，路线候选获得第二个可复核成员；
2. **拆分**：同名机制实际因对象、接口或选择权不同而分叉；
3. **否决**：所谓共同路线只剩语言相似，撤回为独立论文观察。

任何结果都必须回写 `02_CANONICAL12_SOURCE_FIRST_ROUTE_WORKBOOK.md` 的对应行，并附来源定位。
