# 00 — 重建宪章与权威规则

**状态：ACTIVE — 仅新增控制层；不覆盖、不删除既有研究。**  
**任务：**从 12 篇核心论文重建 *planning-centric WAM* 的技术路线；产物必须是可由原始材料追溯的机制比较，而不是把历史命名体系重新包装为结论。

## 0. 本次重建解决什么

仓库积累了原文、代码审计、比较矩阵、外部综述、路线草案和本体实验。它们并非同一证据等级，且不同分支的“READY / STABLE / normative”状态彼此冲突。本层不裁定论文结论；它只规定：以后哪些材料可作为事实、可作为工作假说、只能作为历史记录。

## 1. 结论权威顺序

1. **一级：直接证据。** `papers/raw_md/` 的论文原文、固定版本的官方代码、数据/评测配置和可复核定位。没有直接证据时写 `UNKNOWN`，不补猜。
2. **二级：受范围约束的解释。** 单篇 deep analysis、source/code audit、文献审计。它们保留其来源、版本与适用模式，不因被引用而升级为论文事实。
3. **三级：来源优先读取协议。** pilot 分支的 Q1–Q5、mode split、paper/code/inference 分栏可作为统一记录格式；它尚未定义技术路线。
4. **四级：待检验的综合。** core-route 分支的中性机制记录、Core-Bridge 检验和六个最小机制程序，可作为反例检查与路线候选，不能作为已接受分类。
5. **五级：历史性组织尝试。** V1/V1.3、R/W/E/L、D01/D02、旧 route map、旧状态页与卡片层。保留可复用观察，但不继承其标签、代码或“稳定”声明。

若低等级材料与高等级材料冲突，低等级材料必须降级或拆成待核验项。

## 2. 不变的研究对象

固定核心语料为：P0001 Epona、P0009 DriveLaW、P0042 WorldDrive、P0045 WoTE、P0046 World4Drive、P0048 LAW、P0049 Drive-JEPA、P0061 SeerDrive、P0062 Metis、P0063 DynFlowDrive、P0064 Discrete-WAM、P0065 GraphWorld。

分析中心是**规划因果链**，不是视频是否可解码、也不是抽象地判断“有没有 world model”。每个记录必须区分训练、预训练、微调与部署；同一论文的不同 artifact / inference mode 允许进入不同路线，禁止强行一篇一标签。

## 3. 最小证据记录：Q1–Q5 + 边界

- **Q1：**未来相关计算位于何模块、接口或程序？
- **Q2：**其对象是何种未来：视觉、BEV、latent、关系状态、候选后果、监督目标，或其他？
- **Q3：**该信号是否进入动作链；若进入，经过何接口？
- **Q4：**它在训练或部署中扮演什么作用：表征/监督、单路径条件、候选后果评估、评分/选择、迭代修正等？
- **Q5：**部署保留、旁路或删除哪些模块？

每条回答均附 `PAPER FACT`、`CODE FACT`、`OUR INFERENCE`、`UNKNOWN / NOT REPORTED` 之一，并写明 artifact / mode。

## 4. 何时才提升为“技术路线”

只有同时满足以下条件才可从工作簿提升：

- 至少两篇、或同一论文两个清晰可复核的部署模式共享同一因果分叉；
- 分叉不能仅靠“有未来预测 / 联合训练 / 迭代”这类宽泛措辞定义；
- 能回答世界相关对象的生命周期、是否跨越核心桥进入决策、是否存在候选承诺/选择；
- 反例未推翻该分叉，关键来源与版本边界已写清。

单例保留为**机制个案**，不伪装成路线。
