## 0. Audit question

This audit does **not** ask whether Sets A–E can now be compressed into a route taxonomy.

It asks a narrower set of consistency questions:

1. Did later Sets contradict earlier paper-level factual claims?
2. Did later Sets reveal that an earlier distinction was only an artifact of wording, substrate, or comparison level?
3. Which distinctions have independently reappeared across multiple Sets without being used as the reading prompt?
4. Which apparent regularities are still supported by only one local cluster and therefore remain unsafe to promote?
5. Which unresolved evidence debts could still reverse a material conclusion?

The acceptance criterion is intentionally conservative:

> A distinction may be called **cross-set stable as an audit question** only if independent Sets repeatedly require it to avoid false equivalence. This does **not** make it an ontology axis.

# 1. Overall result

## Result: CONSISTENT-WITH-OPEN-PRESSURES

No hard contradiction was found that requires retracting a paper-first reconstruction in Sets A–E.

The important changes across the five Sets are mostly **refinements of comparison level**, not factual reversals.

The strongest common lesson is negative:

> surface similarities repeatedly fail as mechanism identities.

Across independent Sets, the following words/shells each proved insufficient by themselves:

```text
candidate → future → score
coupling
future prediction / predictive latent
joint / unified world-action
iterative / reciprocal
```

This repeated failure is itself consistent across A–E.

However, the audit does **not** support replacing those failed labels with a new universal coordinate system. The recurring questions below are stable enough to guide reading, but not yet justified as independent ontology dimensions.

---

# 2. Apparent contradiction 1: deployment topology matters, but deployment-only taxonomy can fail

Set A repeatedly uses deployment causal structure to distinguish methods. For example, WoTE keeps online recurrent future BEV evaluation, while WorldDrive keeps a distilled future surrogate and removes the heavy diffusion generator.

Set C later warns:

> `runtime artifact difference != automatically different world-model research idea`

Drive-JEPA is the key case: the simple direct decoder and the full proposal-resolved planner have different commitment graphs, but both inherit the same driving-domain V-JEPA predictive-representation program.

These statements are **consistent once the comparison level is explicit**.

### Artifact-level question

```text
How is the final action committed at runtime?
```

Deployment topology is decisive here.

### Scientific-program question

```text
What role does predictive/world learning play in the paper's research contribution?
```

Deployment topology alone can over-split one paper's program.

### Consistency judgment

No contradiction.

The correction is:

> deployment topology is a necessary factual reconstruction, but it is not a universal scientific-lineage classifier.

This distinction should remain mandatory in future audits.

---

# 3. Apparent contradiction 2: scorer semantics are not a universal axis, but evaluation can be core

Set A preserves the earlier objection that scorer semantics are probably not a globally orthogonal headline axis.

But SafeDrive shows that fine-grained agent×time safety reasoning is central to its scientific contribution: sparse representation alone does not explain the main gain.

Set D independently repeats this pressure through Gen-Drive:

```text
joint social-future generation
+
learned future evaluation
```

Both are essential halves of its generation→evaluation planning program.

Meanwhile other papers use scoring as a more downstream commitment device without making scorer structure the main scientific proposition.

### Consistency judgment

No contradiction.

The stable statement is:

```text
not globally orthogonal
!=
scientifically minor in every paper
```

Therefore future audits must not either:

- promote evaluator semantics automatically into a universal route axis; or
- demote every evaluator to a cosmetic profile.

Its causal role must be reconstructed locally.

---

# 4. Apparent contradiction 3: “future generation removed at inference” versus “world state remains online”

Set B is the clearest correction to an older binary lifecycle reading.

Epona can disable VisDiT during trajectory planning, but the planner still consumes the shared MST temporal state `F` that was jointly shaped by visual and trajectory objectives.

DriveLaW/ReWorld do not require decoding a final future video either, yet online Video-DiT internal generative computation remains on the planner path.

Metis and SimWAM remove future-video generation from action inference more completely, but their training information flow is different from one another.

Set C independently confirms the same principle for predictive learning:

- LAW: predictor output absent online, but action-conditioned predictive loss shapes the deployed planner/representation;
- ViDAR / Drive-JEPA: predictive pretraining acquires a transferred encoder;
- Latent-WAM: DLWM disappears, current SCWE world state remains;
- Auto-JEPA: the predicted future intent itself remains online.

### Consistency judgment

No contradiction.

`future/world output absent at inference` is only a lifecycle fact.

The stable audit question is:

> What exact representation/computation survives online, what does the action path read, and how was it shaped by world/predictive learning?

---

# 5. Apparent contradiction 4: one paper can contain multiple mechanisms, yet artifact splitting remains useful

Set A explicitly rejects `one paper = one route` as a default assumption through WorldDrive and World4Drive.

Set C strengthens the point with Drive-JEPA:

```text
paper level
scientific-program level
runtime-artifact level
```

are all legitimate units for different questions.

Set D repeats the same result with Discrete-WAM and Gen-Drive. Discrete-WAM contains:

- shared discrete representation alignment;
- world modeling;
- world-policy joint training;
- hierarchical policy construction.

Set E likewise shows that one paper can contain a main loop plus auxiliary predictive tasks without those being the same mechanism, as in iPad.

### Consistency judgment

No contradiction.

The corrected rule is:

> artifact splitting is useful for preserving causal/runtime differences, but artifact boundaries must not automatically be promoted into scientific route boundaries.

Future comparison must declare its unit before making sameness/difference claims.

# 6. Cross-set stable audit invariant 1: reconstruct the predictive/world object semantically

This requirement independently appears in every Set.

### Set A

“future” may be:

- endpoint latent;
- recurrent BEV sequence;
- distilled future surrogate;
- candidate-specific decision-adapted latent;
- sparse interaction world with agent×time risk structure.

### Set B

planner-facing world knowledge may live in:

- shared upstream temporal state;
- internal Video-DiT denoising state;
- current observation representation shaped by joint training.

### Set C

prediction targets include:

- future scene latent;
- masked spatiotemporal video representation;
- future point cloud;
- future scene+ego world-status state;
- future ego-trajectory intent latent.

### Set D

“joint” variables include:

- occupancy scene + ego token state;
- interleaved image/action language;
- ego+agent structural trajectory future;
- multi-agent social future scenario;
- multiple world/action/decision token task modes.

### Set E

iterated predictive objects range from future BEV to surrounding-agent motion to graph state; some methods have no qualifying online world state at all.

### Stability judgment

**Strongly replicated as a reading requirement.**

But this does not yet justify a `WorldObjectType` ontology axis. The semantic object must be recorded because failing to do so repeatedly causes false merges.

# 7. Cross-set stable audit invariant 2: forward/deployment graph and learning/backward graph must be separate

This first became explicit in Set B but is independently supported by A, C, D, and E.

## Forward/deployment graph

Asks:

```text
what state actually reaches final action commitment online?
```

Examples:

- WoTE: candidate-specific recurrent predicted future sequence → learned reward → selection;
- DriveLaW/ReWorld: online generator internal state → Action DiT;
- Auto-JEPA: predicted intent → trajectory retrieval → selection;
- OccWorld: predicted joint scene+ego state directly yields ego motion;
- SeerDrive: future BEV enters planner and is revised through feedback.

## Learning/backward graph

Asks:

```text
which predictive/world losses, teachers, or simulators can change deployable action parameters/representations?
```

Examples:

- LAW: predicted ego trajectory participates in the future-latent loss path;
- Metis: future-video objective can influence the action expert despite no future-video→action runtime edge;
- ViDAR: forecasting shapes a transferred encoder;
- WorldDrive: heavy TA-DWM teaches the future surrogate while oracle PDMS teaches preference;
- SafeDrive: external simulator teaches candidate-specific safety while logged agent future is reused.

### Stability judgment

**Strongly replicated as a reading requirement.**

Again, this is not promoted into two ontology axes. It is a minimum reconstruction protocol.

# 8. Cross-set stable audit invariant 3: factorization/order matters

Different Sets reached this result through different disputes.

### Set A

Candidate generation may happen:

- before world reasoning;
- inside intention-conditioned world branches;
- using inherited world representations before later re-ranking.

The same outer `candidate → future → score` shell therefore hides different causal order.

### Set B

Forward visibility is directional:

- Metis: action cannot read future-video tokens; future-video tokens can read future action;
- SimWAM: future-video and future-action tokens are mutually invisible.

### Set C

LAW differs from Latent-WAM because the planner-predicted trajectory explicitly conditions LAW's future-latent learning problem, while Latent-WAM predicts from historical world-status context.

### Set D

DrivingGPT and Discrete-WAM show that “joint sequence” still has factorization. Action and visual tokens do not become causally symmetric merely because they share one model.

### Set E

The loop-closure location and time scale matter:

- SeerDrive: refinement rounds around one planning decision;
- Drive-OccWorld: temporal rollout into later predicted future states;
- PPAD: stepwise ego↔agent future interaction;
- GraphAD/iPad: loops close inside interaction representation or proposal feature extraction.

### Stability judgment

**Strongly replicated as a reading requirement.**

Natural-language words such as `joint`, `iterative`, `coupled`, or `future-aware` are unsafe without an explicit variable-level factorization.

# 9. Cross-set stable audit invariant 4: final commitment mechanism must be separated from world-learning mechanism

This distinction recurs across independent Sets.

Examples:

- WorldDrive: representation inheritance + future surrogate are world-learning transfers; candidate selection is a downstream commitment mechanism.
- Drive-JEPA: V-JEPA pretraining is shared across direct and proposal-resolved planners; commitment differs downstream.
- GenAD vs Gen-Drive: similar multi-agent future objects, but one directly commits generated ego future while the other evaluates generated futures before commitment.
- Discrete-WAM: world-policy training is not identical to the final hierarchical action-editing planner.
- iPad: proposal-centric prediction tasks train representations; final deployed commitment is proposal refinement + scorer.

### Stability judgment

**Strongly replicated.**

The project should not infer the paper's world-model research mechanism solely from how the final trajectory is selected, nor infer final commitment topology solely from the existence of world-policy training.

# 10. Cross-set stable audit invariant 5: domain qualification and mechanism topology are separate problems

Set C exposes this with Auto-JEPA and ViDAR.

- Auto-JEPA has a highly causal online predictive latent, but its target is future ego motion rather than clearly external world evolution.
- ViDAR has genuine future-world forecasting pretraining, but may be adjacent/general predictive representation work rather than a WAM+one-stage planning mechanism.

Set E independently confirms the same separation with PPAD:

- PPAD has strong deployed reciprocal prediction↔planning;
- that beautiful topology does not itself establish WAM membership.

GraphAD and iPad add further negative controls: future trajectories, interaction, candidate conditioning, scoring, and iteration can exist without an online world-model consequence loop.

### Stability judgment

**Strongly replicated.**

The WAM/domain gate must be resolved independently before topology is used for route reasoning.

---

# 11. Cross-set stable audit invariant 6: substrate is not enough

A–E repeatedly show that RGB / BEV / occupancy / latent / token / sparse graph / trajectory space cannot by themselves define mechanism identity.

The same substrate can support different roles, and different substrates can instantiate similar causal relations.

Examples:

- future BEV can be recurrent candidate evaluation (WoTE) or feature-level mutual refinement (SeerDrive);
- latent futures can be factual-branch matching (World4Drive), heavy-WM-distilled surrogates (WorldDrive), or co-adapted candidate futures (DA-WAM);
- trajectory spaces can be direct joint generation (GenAD), generation→evaluation (Gen-Drive), agent↔ego interactive prediction (PPAD), or proposal self-refinement (iPad).

### Stability judgment

**Strongly replicated.**

Representation substrate remains descriptive evidence, not route identity.

# 12. Repeated distinction with medium support: counterfactual grounding provenance

Set A exposed this most strongly:

- factual-future branch matching;
- simulator-generated candidate future truth;
- heavy-world-model teacher futures;
- expert-only observed future + indirect alternative supervision;
- candidate-specific safety labels but reused logged agent futures.

Set D partially repeats the importance through Gen-Drive's learned evaluator/preferences and Discrete-WAM's counterfactual world-model use.

Set E adds Drive-OccWorld-style action-conditioned future rollout, but this Set does not independently analyze alternative-future supervision provenance to the same depth.

### Stability judgment

**Meaningful repeated pressure, but not yet cross-set mature enough for promotion.**

Keep asking:

```text
For an unexecuted action, what exactly grounds the predicted consequence?
```

Do not yet create a counterfactual-grounding axis.

# 13. Repeated distinction with medium support: evaluator/reward can be compiled into generation or remain online

Gen-Drive shows reward-model knowledge can partly be compiled back into the generator through RL, making single-sample generation more capable.

SimWAM separately shows a post-training RL stage on the standalone action expert after video/world co-training.

WorldDrive distills heavy future generation into a lightweight future surrogate while keeping scoring online.

DynFlowDrive is not in Sets A–E, so the strongest future-state-versus-evaluation-distillation contrast from earlier work is outside this audit.

### Stability judgment

Interesting but **not yet a stable A–E route distinction**.

The relation among:

- explicit online consequence;
- distilled consequence representation;
- distilled evaluator/value;
- policy/reward post-training

needs a dedicated cross-paper audit later.

# 15. Hard evidence debts that could still change material conclusions

## 15.1 SeerDrive paper/code equivalence

Set E intentionally reconstructs the paper mechanism and preserves the earlier warning that code-level behavior may not exactly instantiate the paper's reciprocal semantics.

This remains a material unresolved item because SeerDrive is currently the strongest example of same-decision world↔planning mutual refinement.

Before using SeerDrive as a route anchor, re-audit released code against the paper's planner→world feedback edge.

## 15.2 SimWAM gradient/parameter carrier

The paper reports separate experts, mutual invisibility between future action/video tokens, and a strong gain from video co-training.

The exact parameter-level path through which the video objective changes the deployed action representation remains insufficiently traced.

Do not make stronger claims about gradient flow than the paper/code evidence supports.

## 15.3 Evidence parity for papers without local raw-paper artifacts at audit start

Sets B/C/E include cases reconstructed from official external primary text because a local raw artifact was absent at the time:

- SimWAM;
- Latent-WAM;
- PPAD.

Their reconstructions are usable, but evidence handling is not perfectly symmetric with fully local raw-paper cases. Local archival/source closure would improve reproducibility.

## 15.4 Domain membership pressure cases

The following should not be silently treated as settled WAM+one-stage exemplars merely because they were useful in paper-first comparisons:

- ViDAR;
- Auto-JEPA;
- PPAD;
- GraphAD;
- iPad;
- potentially GenAD depending on the eventual world-state gate.

They are scientifically valuable precisely because some are boundary/negative-control cases.

## 15.5 Discrete-WAM versus historical `RJ/W5` compression

Set D reconstructs the final downstream planner as hierarchical decision prediction + action-token editing, while joint world-policy generation is one training/task mode within a broader architecture.

Therefore historical summaries that equate the paper's joint mode with its unique deployed commitment topology remain under pressure.

No historical ontology file is changed here.

# 17. What A–E actually justify now

After 25 paper reconstructions, the strongest result is a **stable reconstruction protocol**, not a stable route taxonomy.

For any future paper, the following minimum record is now justified by repeated failure analysis:

```text
1. Scientific problem / proposition
2. Predictive/world object semantics
3. Forward/deployment graph
4. Learning/backward graph
5. Training vs deployment lifecycle
6. Exact factorization / visibility / loop closure
7. Candidate or action identity through the computation
8. Final commitment mechanism
9. Factual / counterfactual supervision provenance
10. Core-mechanism deletion result
11. Comparison unit: paper, program/component, or runtime artifact
12. Domain/world qualification kept separate from topology
```

These are **audit fields/questions**.

They are not accepted ontology axes.

# 18. Promotion check

No recurring distinction currently satisfies a conservative promotion rule of:

```text
independent replication across multiple Sets
+
clear mechanism-level necessity
+
negative controls
+
no unresolved semantic/domain ambiguity
+
no obvious factorization into lower-level relations
```

The closest candidates are not route categories but reconstruction invariants:

- forward vs learning causal graph;
- lifecycle/retention;
- predicted/world object semantics;
- factorization/order;
- commitment path;
- comparison unit.

Promoting them now would risk replacing the old ontology with a new coordinate system before field-level saturation.

Therefore this audit explicitly recommends **NO ONTOLOGY PROMOTION**.

# 19. Conservative next step

Do not immediately start another five-paper Set merely to increase sample count.

The highest-value next operation is evidence closure on the few cases that currently carry disproportionate conceptual weight:

1. SeerDrive paper↔code reciprocal-loop equivalence;
2. SimWAM source-level learning/gradient carrier;
3. local archival/evidence parity for SimWAM, Latent-WAM, PPAD;
4. explicit domain-gate recheck for Auto-JEPA, ViDAR, PPAD, GraphAD, iPad, and GenAD;
5. only after those closures, run a deliberately adversarial cross-set pair audit on the strongest candidate recurring relations.

Candidate pair audits should be selected to **break** an abstraction, not to confirm it. Examples:

```text
LAW vs Epona
training-time prediction shapes deployment state, but through different causal programs

WorldDrive vs DriveLaW
both inherit/gain world knowledge online, but one uses a distilled candidate future while the other uses generator-internal state

GenAD vs OccWorld
both directly generate ego with other future variables, but in different state spaces and factorisations

SeerDrive vs PPAD
both bidirectional, only one is clearly formulated around a predicted future world representation

WoTE vs Drive-OccWorld
both use explicit predicted physical futures for planning, but one evaluates candidates through rollout while the other closes a temporal forecast-plan loop
```

These pair audits should still avoid route labels.

# 20. Final consistency verdict

The paper-first reset is currently behaving as intended.

Across A–E:

- later Sets mostly **refine** earlier statements instead of contradicting them;
- every attempted surface compression (`candidate-future-score`, `coupling`, `future prediction`, `joint`, `iterative`) has been successfully resisted when full mechanisms differ;
- the same deeper reconstruction questions reappear independently across different scientific disputes;
- the remaining instability is concentrated in evidence debt and domain qualification, not in a need to invent new ontology codes.

The correct interpretation is therefore:

> **A–E are internally coherent enough to continue as a paper-first evidence program, but not mature enough to justify a new route taxonomy.**

No ontology files are modified by this audit.
